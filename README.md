# Kvízová Aplikácia na Prijímacie Skúšky

Kompletná webová aplikácia v **React + TypeScript + Vite + Tailwind CSS**.

## Vlastnosti
- 🔀 **Zamiešanie otázok aj odpovedí:** Pri každom štarte sa náhodne zamieša poradie otázok a zároveň aj možnosti odpovedí so zachovaním správneho vyhodnotenia.
- ⏱️ **Časový limit:** Odpočet 30 sekúnd na otázku.
- 💡 **Vysvetlenia:** Zobrazenie teoretického vysvetlenia po zadaní odpovede.
- 🎨 **Moderné UI:** Dark mode, sklenený efekt (`backdrop-blur`) a ikonky z `lucide-react`.

## Ako spustiť projekt

1. Rozbaľ ZIP archív:
   ```bash
   unzip quiz-app-react-typescript.zip
   cd quiz-app
   ```

2. Nainštaluj závislosti:
   ```bash
   npm install
   ```

3. Spusti aplikáciu vo vývojovom režime:
   ```bash
   npm run dev
   ```

4. Otvor prehliadač na adrese `http://localhost:5173`.
